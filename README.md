# 🏋️‍♂️ RihanFitness

A modern, responsive, and feature-rich fitness web application designed to help users track workouts, explore fitness routines, and stay motivated on their health journey. Built with clean web technologies and deployed seamlessly.

## ✨ Features

- **Responsive Design:** Optimized seamlessly for mobile phones, tablets, and desktop screens.
- **Interactive Workouts:** Guided exercise categories and routine breakdowns.
- **Modern UI/UX:** Clean aesthetics with smooth transitions and intuitive navigation.
- **Fast Performance:** Lightweight codebase optimized for quick loading times.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (Flexbox, Grid, custom styling)
- **Scripting:** Vanilla JavaScript (DOM manipulation, interactive elements)
- **Version Control:** Git & GitHub
- **Deployment:** Vercel
